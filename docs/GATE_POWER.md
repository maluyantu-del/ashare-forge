# 门槛检验力与试验计数披露

本文给出现行分层门槛在平静期夏普维度上的检验力,即给定真实夏普时的通过概率,以及 DSR 门槛随试验数 n 收紧的幅度。

**本分析只作披露,不改门槛。** 门槛数值与 `overall_pass` 的判定逻辑未作任何改动。如要调整门槛,须合同升版,且只对升版之后的批次生效;既往试验照计 n,既往裁定不重判。

**功效不足 = 未通过。** 见第 5 节。

## 1. 口径

**标准误。** 逐期夏普估计量在偏度 γ₃、峰度 γ₄(非超额)下的渐近方差取

```
Var(SR̂) = (1 − γ₃·SR + (γ₄ − 1)/4 · SR²) / (T − 1)
```

年化时乘 √243。该式即 `gates.psr` 的分母。新增的 `gates.sharpe_se` 与之同式;`gates.psr_from_stats` 与 `gates.psr` 逐位一致,由测试钉死。`gates.psr` 本身未改动。

**运气基准。** n 次独立试验、真实夏普均为 0 时的期望最大夏普(Bailey & López de Prado, 2014):

```
SR* = √(1/T) · [ (1 − γ_E)·Φ⁻¹(1 − 1/n) + γ_E·Φ⁻¹(1 − 1/(n·e)) ]
```

年化时乘 √243,γ_E 为 Euler 常数。由 `gates.expected_max_sharpe_ann` 直接给出。

**所需观测夏普。** DSR ≥ 0.95 等价于 PSR(观测夏普; 基准 SR*) ≥ 0.95。`gates.required_sharpe_dsr_ann` 以二分法求根。偏度 0、峰度 3 时存在闭式解,测试中二者相对误差小于 1e-12;在根的上下各作 1e-7 相对扰动,`gates.dsr` 恰好跨过 0.95。

**通过概率。** 此处"通过"指平静期三道夏普族门同时通过:超额夏普 ≥ 0.8、PSR ≥ 0.9、DSR ≥ 0.95。三者所需观测夏普中的最大者为约束值。T = 1990 时,n ≥ 3 即由 DSR 约束;n = 2 时 DSR 所需值为 0.757,约束项是 0.8 的固定阈值。给定真实年化夏普 s,取正态近似:

```
P = 1 − Φ( (约束值 − s) / SE(s) )
```

SE 在真实夏普处取值,偏度 0、峰度 3。零校准、危机层与持仓门不在其内,故 P 是整体通过概率的上界。

**蒙特卡洛。** 对模拟日收益直接调用 `gates.ann_sharpe`、`gates.psr`、`gates.dsr` 判三道门。分布取两组:正态;t 分布(自由度 4,缩放至单位方差)。每组 20000 条路径,种子 7,各 n 共用同一组路径。通过比例的标准误上界为 0.0035。t(4) 的四阶矩不存在,样本峰度不收敛:T = 1990 时样本峰度中位数约 8.9–9.0,T = 361 时约 6.6–6.7。

**样本长度。** T = 1990 为 BATCH02 样本的平静期交易日数,T = 361 为危机期交易日数。危机层的实际门槛是超额夏普 ≥ 0,不含 DSR;T = 361 各行只说明该样本长度下夏普的分辨力。

## 3. 读法

1. **运气基准已接近固定阈值。** T = 1990 时,n = 20–50 对应的运气基准为 0.66–0.80。即使全部试验的真实夏普为 0,n 个试验中最好的一个,其观测夏普的期望也已接近 0.8 这一固定阈值。DSR 扣除的正是这一部分。
2. **所需观测夏普为 1.24–1.37。** n 由 20 增至 50,所需值上升 0.13。BATCH02 结束时 n = 38,所需值 1.33,与 `tasks/BATCH02_FINDINGS.md` 中"约 1.3"的估计一致。
3. **检验力低。** n = 38 时,真实年化夏普 0.8 的通过概率为 6.3%,1.0 为 17.0%。通过概率要达到 80%,真实夏普须约 1.63。换言之,仅计平静期夏普族门,真实夏普为 1.0 的因子也约有 83% 的概率被判未通过。
4. **平静期的厚尾偏差可忽略。** T = 1990 时,解析值与正态蒙特卡洛相差不超过 0.001,与 t(4) 蒙特卡洛相差不超过 0.002,均在蒙特卡洛标准误以内。原因是日频逐期夏普仅约 0.05–0.09:即使样本峰度为 9,峰度项 (γ₄−1)/4·SR² 在方差中的占比也不超过约 1.5%。T = 361 时,t(4) 的通过比例略高(n = 20、真实夏普 1.0 时为 0.013,解析值 0.010),但绝对水平均不超过 1.3%。
5. **危机层分辨力有限。** T = 361 时年化标准误为 0.82,90% 区间半宽 1.35。真实危机期夏普为 0 时,观测值 ≥ 0 的概率为 50%;真实值为 0.5 时为 73%。"危机期超额夏普 ≥ 0"一项的裁定在很大程度上受抽样噪声支配,与 BATCH02 局限第 2 条一致。

## 4. `gates.evaluate` 的披露行

`gates.evaluate` 在 `overall_pass` 算定之后,追加 `layer='disclosure'` 的行。这些行 `required=False`、`passed=None`、`threshold=None`,不进入判定。

| gate | 含义 |
|---|---|
| `excess_sharpe_se_ann` | 平静期超额夏普的年化标准误,取观测偏度与峰度 |
| `excess_sharpe_ci90_lo`、`excess_sharpe_ci90_hi` | 平静期超额夏普的 90% 区间 |
| `sr_required_dsr95(n=N)` | 当前 n 下 DSR ≥ 0.95 所需的观测年化夏普,取观测偏度与峰度;观测夏普越过此值与 DSR 行通过等价 |
| `sr_required_calm_binding` | 三道夏普族门所需值中的最大者 |
| `p_pass_calm\|true_sr=0.8`、`p_pass_calm\|true_sr=1.0` | 通过概率,定义同第 1 节,高阶矩取观测值 |
| `n_trials_breakdown` | n_trials 的构成,格式为 `history=H + declared=D = total N`,由 pipeline 调用处传入 |
| `verdict_label` | 三态标签,另作为返回值键 `verdict_label` 给出 |

披露行的 gate 名均不以 `dsr` 开头,因为 pipeline 写台账时按此前缀提取 DSR 值。

`tests/test_gates_power.py` 冻结了改动前的实现,在 270 个组合上逐项比对:9 类合成回测 × 6 类零校准结果 × 5 个 n。比对项为 `overall_pass`、`null_passed` 与全部非披露行,结果一致。

## 5. 三态标签

| 标签 | 条件 |
|---|---|
| `PASS` | `overall_pass` 为真 |
| `FAIL-已否证` | 未通过,且平静期超额夏普 90% 区间上界 < 0.8:样本足以排除"真实夏普 ≥ 0.8" |
| `FAIL-功效不足` | 未通过,且区间上界 ≥ 0.8,即区间未排除 0.8;平静期样本不足 30 天、区间不可得时亦归此类 |

**功效不足 = 未通过。** 该标签只说明当前样本不足以排除参照夏普,不构成放行、降低门槛或优先复试的依据。对同一假设的任何复试,包括换参数、换窗口或换样本,都计入试验数 n,使其后的 DSR 门槛进一步收紧。

两条边界约定:

- 区间上界恰为 0.8 时,归为"功效不足"。否证要求上界严格小于 0.8。
- 区间整体高于 0.8 而仍未通过时,同样归为"功效不足"。此时未通过源于 DSR、零校准、危机层或持仓门,notes 中会注明原因不在夏普本身。

## 7. 局限

1. 标准误为渐近式,且假设日收益独立同分布。日超额收益若存在自相关(例如持仓延续带来的慢变暴露),实际标准误会偏离上式。蒙特卡洛未模拟波动聚集与自相关。
2. DSR 的运气基准假设 n 次试验相互独立,且试验间夏普方差为 1/T。本研究域的试验共享股票池与样本期,部分因子高度相关(特质波动率与总波动率的截面秩相关为 0.93),有效独立试验数小于 n,基准因此偏保守。反之,台账之外未计入的试验(如参考实现自身的参数选择)会使 n 偏低。两个方向的偏差均未校正。
3. 通过概率只计平静期夏普族门,是整体通过概率的上界。
4. 三态标签的参照值取合同 `gates_draft` 的 0.8,只针对平静期超额夏普这一个维度,不反映零校准与危机层。
5. 第 6 节的所需夏普列按偏度 0、峰度 3 计算,与各因子 DSR 行的实际口径(观测偏度与峰度)略有差异。
