tasks/task02_short_reversal.yaml
经济逻辑与对立假设
短期反转有两条互不排斥的来源。其一是流动性提供补偿——承接恐慌抛压的一方要求回报, 价格被抛压推过头后回归,反转收益是承接的报酬而非预测能力。其二是过度反应—— 噪声交易者对消息反应过度,随后被修正。A 股的放大器在于散户成交占比高, 且 T+1 与涨跌停制度把抛压在时间上拉长,过冲更容易发生。 可证伪的对立假设有三条。(a) 换皮假设——反转只是换手率/流动性因子的另一种写法, 控制换手后 IC 归零。(b) 可投域假设——反转强度随市值下降而上升,本合同剔除 流通市值低于 20 亿与 ST 之后,最肥的一段已经不在池内,剩余部分不足以覆盖成本。 (c) 不可兑现假设——跌幅最大的一端正是最可能一字跌停或停牌的一端,T+1 下买不进, 纸面收益无法实现;任务卡01 已在突破形态上见过同型失败,此处必须独立复核而非假定不同。
假设(拉数据前写死,3 条)
  1. H1: 对齐可交易收益(t+1 开盘到 t+2 开盘)的 RankIC 均值超越逐日截面打乱零分布的 95 分位
  2. H2: 多头组(因子前10%)相对中证500 的超额夏普超越零分布 95 分位,且超额年化收益为正
  3. H3: 2017-01-01 之后子样本的 IC 均值不低于 2017-01-01 之前子样本 IC 均值的一半
证伪条件:H1 不成立 → 该因子在本可交易口径下不具截面选股能力,结论为负,存档不再扩展。 H2 不成立(含"零校准通过但超额年化不为正"的情形)→ 有微弱截面信息但不可交易, 与任务卡01 同型;H2 的两条判据必须并用,因为任务卡01 实测过"零校准 5/5 通过却年亏 20%", 只用零校准会把亏损因子判成立,只用固定阈值又对零假设不设防。 H3 不成立 → 结论限定为"历史有效、近段衰减",任何面向当下的部署主张作废, 且不得再用全样本均值作为结论;H3 成立则"拥挤致衰减"的流行叙事在本口径下被证伪, 这同样是一条值得交付的结果。 补充判据——若剔除"建仓日一字跌停或停牌而买不进"的标的后超额收益衰减超过一半, 则判为"效应真但不可兑现",与 H2 不成立同等处理。
已知死路 / 不可采信来源
  • 2017 年后衰减是公开研究的普遍报告,常见归因为机构化、量化产品同质化与策略拥挤。 因此"用全样本均值宣称有效"会被 2017 年之前的高收益段拉高,分段报告是必需项而非可选项。
  • 微盘依赖——反转强度随市值下降而上升。合同已剔除流通市值低于 20 亿与 ST, 等于切掉该效应最肥的一段;若只在被剔除段内成立,结论应写成"有效但不在可投域内", 而不是"有效"。
  • 换手率换皮——反转与换手/流动性高度相关,不做换手控制的正结果不可采信。
  • 停牌复牌跳价会被误读为新的反转信号。因子用 MAX_STALE_DAYS 桥接加"窗口内最少成交日占比" 两道闸拦截,但长停牌股复牌后的首段仍应视为可疑样本。
  • 一字跌停不可买——跌幅最大的一端正是最可能封死跌停的一端。回测器已执行 can_buy, 但任务卡仍须单独报告"因买不进而被迫放弃的目标权重占比",否则 IC 与净值会讲两个不同的故事。
  • 信号已被压到两日时滞——引擎执行链是 factor[t] 到 t+1 开盘建仓,主口径 skip=1 再压一天, 合计两个交易日。若结论为负,必须先用 skip=0 的对照排除"是时滞吃掉了信号", 再谈"效应消失",否则把执行口径的代价错记成经济结论。

tasks/task03_idio_volatility.yaml
经济逻辑与对立假设
低波异象有两条经典来源。其一是杠杆约束(betting-against-beta)—— 许多资金被禁止或不愿加杠杆,只能靠超配高 beta、高波动资产去追求高收益, 从而推高其价格、压低其预期回报;能够加杠杆的一方做多低波即可收取这份补偿。 其二是彩票偏好——投资者对"小概率暴涨"有系统性偏好,愿意为高波动、高右偏的股票多付钱, 高波组因而被高估。A 股散户成交占比高,理论上第二条渠道更强。 可证伪的对立假设有三条。(a) 市值换皮——A 股的高波与小市值高度相关,低波组近似大市值组, 因子收益只是 2017-2021 大盘风格与 2021-2023 小盘风格轮动的结果,不是独立 alpha。 (b) beta 换皮——低波组合的 beta 小于 1,相对中证500 的"超额"在下跌年份天然为正、 上涨年份天然为负,这是市场暴露的会计效果,不是选股能力。 (c) 特质化不彻底——本口径只扣掉单一市场代理,缺 SMB/HML,残差中仍留有规模与风格暴露, 所谓"特质"波动其实仍含系统性成分。三条都必须被单独检验,不得因为因子名里有"特质"二字 就默认已排除。
假设(拉数据前写死,3 条)
  1. H1: 对齐可交易收益(t+1 开盘到 t+2 开盘)的 RankIC 均值超越逐日截面打乱零分布的 95 分位
  2. H2: 多头组(因子前10%)相对中证500 的超额夏普超越零分布 95 分位,且超额年化收益为正
  3. H3: 因子与流通市值的日均截面秩相关绝对值小于 0.5,且把可投域按流通市值三等分后, 三层内的 IC 均值同号、并有至少两层超越各自的零分布 95 分位
证伪条件:H1 不成立 → 低波在本可交易口径下不具截面选股能力,结论为负,存档不再扩展。 H2 不成立 → 有截面信息但不可交易;此处同样两条判据并用,理由与任务卡02 相同—— 只用零校准会把亏损因子判成立,只用固定阈值又对零假设不设防。 H3 不成立 → 低波在本口径下不是独立因子,而是市值或风格的换皮, 结论降级为"与市值高度重合,不单独立项",并转由组合层判断是否还有增量。 补充判据——若多头组 beta 调整后的超额年化不为正,则判为"超额来自低 beta 而非选股能力", 与 H2 不成立同等处理。
已知死路 / 不可采信来源
  • 市值换皮是本卡最大的风险,必须单独检验,不得默认已排除。A 股波动率与流通市值负相关强, 低波因子很可能只是"买大市值";而市值风格在样本期内多次反转(2017-2020 大盘占优、 2021-2023 小盘占优、2024-01 微盘流动性危机),一个市值换皮的低波因子会表现出 强烈的分段不稳定,却可能在全样本均值上看起来正常。判据见 H3。
  • 与上一条配套的取样陷阱——合同已剔除流通市值低于 20 亿,可投域的市值跨度本就被截断, 这会同时削弱真实的低波效应与市值换皮的表现。当前库内样本(按代码顺序同步, 以沪市主板老股为主)实测低波因子与流通市值的日均截面秩相关仅约 +0.04, 这个数字不能当作"已排除换皮"的证据——它同样可能只说明样本的市值跨度太窄。 该诊断必须在全量同步完成后重算。
  • beta 与 alpha 混淆——多头超额若全部来自 beta 小于 1,则在任何下跌年份都会"有效", 这不是选股能力。须同时报告多头组相对中证500 的 beta 与 beta 调整后的超额。
  • 价格冻结伪装成低波——长停牌与连续一字板会让个股收益恒为零,算出极低甚至为零的波动, 取负后排在多头组最前。因子已设两道闸(估计量为正,且个股自身收益标准差为正), 其中第二道闸是自测实测发现的必需项——excess 口径把 beta 固定为 1,冻结股的超额收益 等于市场收益的相反数,标准差恰好等于市场自身波动,只查"波动大于零"拦不住。 但复牌后的首段仍应视为可疑样本。
  • 单因子残差不等于特质——免费数据下没有现成可靠的 SMB/HML 因子收益序列, 本口径的"特质"只是扣掉市场代理后的残差。这是数据边界而非已解决的问题,须在结论中披露。
  • 频率口径分歧——低波异象在月频调仓的文献中最强;本引擎为日频信号、窗口 60 日, 换手更高、成本侵蚀更重。日频不成立不能推断月频也不成立,反之亦然; 结论必须带上调仓频率的限定词。

Amihud非流动性

  • 还是说它只是流通市值的单调变换——非流动性溢价实为小市值溢价换皮?

tasks/task04_illiquidity.yaml · 因子插件 ashare_forge/factors/illiquidity.py
经济逻辑与对立假设
Amihud(2002)的非流动性溢价假说:交易一只股票的冲击成本越高,持有者要求的预期收益越高, 差额是对未来变现成本的补偿。在 A 股还有一条同向的本土证据链——换手率因子长期为负, 即高换手(高流动性、高投机度)的股票后续收益偏低;低换手股对应低成交额、高 Amihud 值。 两条逻辑指向同一符号,故方向可以在拉数据前单一申报,不留事后挑符号的余地。 可证伪的对立假设:(a) 该因子只是流通市值的代理,市值中性化后信息归零; (b) 冲击成本本身就是交易成本——即便毛收益为正,按合同的单边 0.125% 成本(对流动性最差的 一端其实还偏乐观)扣完后净额为负,属因子真但不可交易; (c) 在 T+1 与涨跌停约束下,最不流动的一端恰恰是买不进、卖不掉的那一端。
假设(拉数据前写死,4 条)
  1. H1: 主口径 RankIC 超越零分布 95 分位(具有真实截面选股能力)
  2. H2: 多头组相对中证500 的超额夏普超越零分布 95 分位
  3. H3: 市值中性化后(T2),RankIC 仍超越其自身的零分布 95 分位
  4. H4: 把合同成本翻倍(单边 0.25%)后,多头超额年化仍为正
证伪条件:H1 或 H2 不成立 → 该因子在本口径下不具可交易的截面选股能力; H3 不成立 → 非流动性无独立于市值的信息,记为市值代理,结论按此写,不得只报主口径; H4 不成立 → 记为因子真但被自身的交易成本吃掉,属不可交易。 另:零假设校准通过不等于赚钱(任务卡01 实测过零校准 5/5 通过却年亏 20%), 绝对门槛与零分布判据必须并列呈现。
已知死路 / 不可采信来源
  • 非流动性与市值高度相关,可能只是小市值换皮。实测(2019-01-02→2024-08-30,库内 611 只) ILLIQ 与流通市值的日均截面秩相关 = -0.84,共同变动约七成。因此主口径单独跑出正结果 不足以立论,必须与 build_factor_size_neutral 并列汇报:中性化后若信息归零, 结论应写成「非流动性无独立信息,原始效应由市值承担」。 中性化后残差与市值的秩相关降至 -0.08;不为 0 是因为残差只对市值秩做了线性正交, 单调非线性部分仍有残留,这一点须在结论中披露,不得宣称完全中性。 (该相关系数随样本扩大稳定:库内 413 只时 -0.85,611 只时 -0.84。)
  • 非流动性因子的回测收益与冲击成本是同一件事的两面:因子值最高的一端,正是实际冲击成本 被合同固定值(单边 0.1%)低估得最多的一端。故毛收益为正而净收益为负是本因子的典型归宿, 须按平静/危机分层复核成本敏感性(成本翻倍档,见 H4)。
  • 合同已剔除流通市值<20亿与次新股,天然砍掉了 Amihud 效应最强的尾部; 本卡的结论只对「流通市值20亿以上、上市满120交易日、非ST」的池子成立,不得外推到全市场。
  • 本库 adj_factor 表覆盖远落后于 daily 表,adj_close 对多数股票退化为原始 close; 故本因子的收益口径改用 pctChg(已含除权调整),不依赖复权因子表。 但回测器 backtest 仍用 adj_close 算持仓收益,该处的偏差不在本卡可控范围内,须一并披露。

经济逻辑与对立假设
价值溢价的标准解释:高 E/P 意味着单位价格买到更多当期盈利,若市场对盈利的持续性定价过低, 持有高 E/P 组合可获得均值回复的补偿;风险解释则认为高 E/P 是困境风险的定价,溢价是风险报酬。 可证伪的对立假设:(a) A 股的价值溢价在 2017-2021 的成长风格中长期为负,若样本内正结果 完全由个别片段贡献,则属区制依赖而非稳定因子; (b) E/P 的截面差异主要由行业构成决定(银行/地产天然高 E/P),行业中性化后归零; (c) 正结果来自 peTTM 的发布时滞——即因子值提前知道了尚未公告的盈利。
假设(拉数据前写死,5 条)
  1. H1: 主口径(T1)RankIC 超越零分布 95 分位
  2. H2: 多头组相对中证500 的超额夏普超越零分布 95 分位
  3. H3: lag=60 档相对 lag=0 档(T3)的 RankIC 衰减不超过一半
  4. H4: 仅正盈利档的 RankIC 与保留负盈利档同号,且量级不低于其一半; 若不成立,说明信号由亏损股尾巴驱动,属困境/壳价值而非估值。
  5. H5: 按年度分解后正贡献不集中于单一年份(最大单年贡献占比 < 50%)
证伪条件:H1 或 H2 不成立 → 该因子在本口径下不具可交易的截面选股能力; H3 不成立 → 效应来自披露时点(数据前视嫌疑),结论不得写成估值有效; H4 不成立 → 效应来自亏损股尾巴,应改立困境反转任务卡重新申报; H5 不成立 → 记为区制依赖,不得作为稳定因子进组合层。 绝对门槛与零分布判据必须并列呈现:任务卡01 已实测零校准 5/5 通过却年亏 20%。
已知死路 / 不可采信来源
  • A股估值因子在 2017-2021 的成长风格下长期失效(核心资产行情中低估值组合持续跑输)。 因此全样本平均值会被区制掩盖,必须按年度以及按合同 regimes 的平静-危机分层分别报告; 只报全样本均值的结论不予采信。
  • peTTM 来自 baostock 为当期快照而非 PIT:存在财报修订与发布时滞导致的前视风险, 本平台无法完全排除,详见 pit_risk 段。任何正结果都必须与 lag=60 档并列呈现, 若 lag=60 后信号消失,结论应写成「效应来自披露时点而非估值」。
  • E/P 的截面差异高度依赖行业构成(银行、地产、钢铁天然高 E/P)。本平台无 PIT 行业分类 (合同已声明行业为当前快照),故无法做行业中性化;这意味着正结果可能只是一次行业押注。 须在结论中明写该项未被排除,不得以「因子有效」作结。
  • E/P 与非流动性因子(task04)存在明显负相关(实测日均截面秩相关 -0.33,同上样本), 两卡若同时进组合层,须按组合层的增量准入规则复核,不得重复计入同一条信息。

诚实披露

限制条目取自 docs/PHASE1-DATA-LAYER.md 与合同 disclosure
  1. 样本覆盖率 98.52%(已同步 5,476 只 / 股池 5,558 只)。覆盖率接近满格之前,任何指标只用于机械验证,不足以支撑研究结论。
  2. 已同步子集不是随机样本:全量同步按股票代码顺序推进,当前已同步的部分集中在代码靠前的区段,存在系统性偏倚;以该子集算出的 IC 与超额收益不可外推到全市场。
  3. 保留段锁定于 2024-09-01:loader 默认不返回该日及以后的数据,解锁需显式 unlock_holdout=True 并写 meta 台账;当前解锁记录 1 条。
  4. 本页只读:数据库以只读模式打开,不建表、不写 meta、不触发同步;页面无外链、无 CDN、无网络请求,仅供本地查看。
  5. baostock 不覆盖北交所:快照前缀只有 sz/sh;合同中 bse 涨跌停 30% 与 is_stock_code 接受 bj.4/8 在本数据源下永远无数据。
  6. 行业分类非 PIT:只有当前快照,历史行业归属不可回溯。
  7. 中证1000 指数含发布前回算段(库内起于 2005,指数 2014 才发布),用于早期分层需披露。
  8. 股池快照为季度:两次快照之间上市又退市的股票会遗漏(极少)。
  9. mark_delisted 依赖日线:未同步日线的股票不会被标记(不会误标,但也不会发现);n_vanished_from_universe 与 n_delisted 的差额即"已知消失但尚未取证"。
  10. 增量同步不回填:若先用晚起点同步过,再改早起点不会补历史(复权因子已用 full_refresh 规避,日线需手工清表重来)。
  11. listing_age 依赖库内历史:若面板起点接近库内最早日期,前 120 个交易日会因"看起来像次新"而整体出池——实测 30 只在 2024 起点下 in_universe 仅 26.3%,正是此故。全量同步 10 年后不再有此问题。
